# 一封信

一个纯静态的「信」页面：手机打开（比如贴一下 NFC 小卡）先看到信封，轻触展开，
文字逐字浮现，**底部一直挂着一小块画布**，随读到的内容实时切换动画——
从早上好的天色，到紫色的洇开，再到用紫色点云聚合出来、扇动翅膀的 3D 蝴蝶，
最后是雨后的一抹彩虹。

- **零依赖、零构建、零外部请求**：只有 `index.html` + 一个 CSS + 一个 JS（内联了 SVG 图案），断网也能跑。
- **完全按手机设计**：`svh` + 安全区适配、画布固定在底部、单列阅读；桌面端自动变成「左信纸 / 右画布」两栏。
- **性能**：画布像素比自适应（大屏自动降一档）、几百条连线批量描边、光晕预渲染，
  在 iPhone 尺寸与 iPad 尺寸下实测稳定 **60fps**。

---

## 快速开始

```bash
# 本地预览（推荐，最接近线上）
python3 -m http.server 8000
# 手机连同一个 WiFi 打开 http://你的电脑局域网IP:8000
```

直接双击 `index.html` 也能看，所有路径都是相对的。

**要传到一个 URL 上 → 看 [`docs/DEPLOY.md`](docs/DEPLOY.md)**（首选 EdgeOne Pages / GitHub Pages，
一条命令：`./deploy.sh <git仓库地址>`）。

| 05 | 在宁夏大学的四年时光……只剩下大三一年 | 大一/大二/大三/大四四根柱子长出来，大三高亮，大四打上斜纹（实习） |

## 交互细节

- **信封开场**：先看到信封和火漆印，轻触后封口翻开、信纸抽出，正文才开始打字。
- **滚动即换动画**：不需要点任何按钮，读到哪，画布演到哪。
- **重播**：轻触（或键盘聚焦后回车）底部画布，可以重播当前动画。
- **从头再读一遍**：结尾的按钮会回到顶部并把所有文字重置成未打出的状态。
- **「向下滑动 · 继续读」**：只在第一次进来时提示，滑动一下或 6.8 秒后自动消失。
- **减弱动态效果**：系统开启「减少动态效果」后，文字直接显示、画面只呈现静止的一帧。
- **没有 JS 也能读**：`<noscript>` 兜底会隐藏信封、直接显示全文。

## 想改点什么

| 想改 | 改哪里 |
|---|---|
| 正文文案 | `index.html` 里的 `<p class="line">`；`data-scene` 决定它配哪段动画 |
| 场景小标签（画布左上角那个） | 同一个 `<p>` 上的 `data-cap` |
| 配色 | `assets/style.css` 的 `:root`，以及 `assets/app.js` 顶部的 `C = {...}` |
| 画布高度 | `style.css` 里的 `--stage-h`（手机默认 `37svh`） |
| 某段动画 | `assets/app.js` 里对应的 `sceneXxx()`，每个场景都是独立函数，画完即返回 |
| 分享卡片 | `assets/og.png`（1200×630，替换同尺寸图片即可） |

想加一个新动画：在 `app.js` 里写一个 `sceneXxx(w, h)`（返回 `{draw(t, dt)}`），
注册到 `SCENES` 里，然后在 HTML 某段上写 `data-scene="xxx"` 就行。

## 兼容性与实测

| 项目 | 结果 |
|---|---|
| 视口 `360×640 / 375×667 / 390×844 / 430×932 / 768×1024 / 1280×800 / 740×360` | 无横向溢出 |
| 文案与原文逐字比对 | 12 段全部一致 |
| 中文标点出现在行首 | 无（标点会并进前一个字） |
| 控制台报错 | 无 |
| 帧率（蝴蝶场景，无 GPU 的 headless 环境） | 手机尺寸 60fps；768 宽 59fps |
| 减弱动态效果 / 无 JS / 打印 | 均有兜底 |

浏览器要求：支持 Canvas 2D 与 `IntersectionObserver` 的现代浏览器（iOS Safari 13+、Chrome 80+ 均可）。
`ctx.filter`（模糊）与 `svh` 不支持时会自动降级，不影响使用。
