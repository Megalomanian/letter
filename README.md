# 一封信

一个纯静态的「信」页面：手机打开（比如贴一下 NFC 小卡）先看到信封，轻触展开，
然后**一页一句地翻**——每次翻页，下方那块常驻画布就换成与这句话对应的动画：
从早上好的天色，到紫色的洇开，再到用紫色点云聚合出来、扇动翅膀的 3D 蝴蝶，
最后一页是信纸折进信封、火漆印按下，画布铺满整屏收尾。

- **零依赖、零构建、零外部请求**：只有 `index.html` + 一个 CSS + 一个 JS（内联了 SVG 图案），断网也能跑。
- **翻页式交互**：上滑 / 点击 / 滚轮 / 方向键都能翻，没有滚动条；桌面端自动变成「左文 / 右画布」两栏。
- **性能**：画布像素比自适应（大屏自动降一档）、几百条连线批量描边、光晕预渲染，
  实测在 iPhone / iPad 尺寸下稳定 **60fps**。

## 快速开始

```bash
# 本地预览（推荐，最接近线上）
python3 -m http.server 8000
# 手机连同一个 WiFi 打开 http://你的电脑局域网IP:8000
```

直接双击 `index.html` 也能看，所有路径都是相对的。

**要传到一个 URL 上 → 看 [`docs/DEPLOY.md`](docs/DEPLOY.md)**（首选 EdgeOne Pages / GitHub Pages，
一条命令：`./deploy.sh <git仓库地址>`）。

## 翻页 ↔ 文案 ↔ 动画 对照表

每一页是一个 `<section class="page">`，用 `data-scene` 绑定一个动画场景（在 `index.html` 里改）。
翻页时画布做 0.55s 交叉淡入；文字第一次翻到时**逐字浮现**，回头再看就是完整的。

| 页 | 正文 | 画布上发生什么 |
|---|---|---|
| 01 | 早上好，下午好，或者晚上好 | 按**当前真实时间**切换天色：晨光/午后/星夜，日月沿弧线移动，云在飘；左下角显示此刻的「早上好 · 08:24」 |
| 02 | 如果你看到这行文字，说明你已经收下了这张小卡 | **一张空白小卡**：只有纸卡、描边和投影，轻微浮动，没有任何文字与图案 |
| 03 | 我还是更倾向于将文字打出来 | 纸面上真的在**逐字打字**，光标跟着闪 |
| 04 | 或许你已经猜到接下来的话 | **粒子汇聚成字**：紫色点云从画布各处带拖尾飞向字形，约 1.2 秒聚成「或许你已经猜到」，随后清晰的衬线字浮出来 |
| 05 | 在宁夏大学的四年时光……只剩下大三一年 | 大一/大二/大三/大四四根柱子长出来，大三高亮，大四打上斜纹（实习） |
| 06 | 于是我决定活得洒脱一些，不再遮掩…… | 与 04 同一套「汇聚成字」手法：换成「洒脱一些 / 不再遮掩」，底下加一层暖光 |
| 07 | 很抱歉，我早就记不得我们第一次在何时…… | 虚线相框里一片模糊的记忆块，浮着问号和「— · —」的未知日期 |
| 08 | 当时的脑海里，只依稀留下黑框眼镜、粉色长裙和高跟鞋 | 三样东西从左到右被「洗」出来，粉色两件带呼吸光（**画布上不再出现任何文字**） |
| 09 | 以及一位刚刚步入大学，富有活力的姑娘 | **pic1.png** 从模糊到清晰浮现成一张照片卡片，落定时收一下缩放 |
| 10 | 紫色，令人产生一些富有生命力的联想 | **紫色从中心洇开**，铺满整个画布，紫色光斑缓慢流动 |
| 11 | 做一只蝴蝶，飞舞在世间，你或许见识到许多风景 | 先是满屏散落的**紫色点** → 点与点**连成线** → 聚合成一只**3D 蝴蝶**，翅膀真实扇动，还会轻微摆头、上下浮动 |
| 12 | 你愿意为雨后乍现的一抹彩虹，短暂驻足吗？ | 先完整播完原有的正方形图像动画（彩虹一段段画出、雨丝落下、撑伞的人、水洼涟漪），**3.4 秒后同一个方框里的画面切换成 pic2.jpg**，由模糊到清晰 |
| 13 | （无正文，只有画布） | 信纸折进信封，火漆印按下，画布长大铺满整屏收尾 |

> 画布上除了动画本身不放任何角标：`01 时间` 这类序号与标题已经全部去掉。

## 交互细节

- **信封开场**：先看到信封和火漆印，轻触后封口翻开、信纸抽出，第一页才开始打字。
- **翻页**：上滑 / 点击 / 滚轮 / `↓` `→` `空格` 往后翻，下滑 / `↑` `←` 往前翻，`Home` / `End` 跳到首尾。
- **画布跟着内容走**：翻到哪一页，画布就演哪一段动画，不需要点任何按钮。
- **手机上翻页为什么可靠**：触摸走原生 `touch` 事件，并且给容器设了 `touch-action: pinch-zoom`。
  如果沿用默认的 `manipulation`，浏览器会把单指纵向拖拽当成滚动接管、把手势掐成 `pointercancel`，
  表现就是"怎么划都翻不了页，只有点击有效"。鼠标/触控板走指针事件，两条通道共用同一份手势状态，不会重复翻页。
- **「向上滑动 · 继续」**：只在第一页出现，翻走或 6.5 秒后自动收起。
- **减弱动态效果**：系统开启「减少动态效果」后，文字直接显示、画面只呈现静止的一帧。
- **没有 JS 也能读**：`<noscript>` 兜底会隐藏信封、把 13 页按顺序摊开成可滚动的长文。

## 想改点什么

| 想改 | 改哪里 |
|---|---|
| 正文文案 / 增减页 | `index.html` 里的 `<section class="page">` 和里面的 `<p class="line">`；`data-scene` 决定它配哪段动画 |
| 配色 | `assets/style.css` 的 `:root`，以及 `assets/app.js` 顶部的 `C = {...}` |
| 画布高度 | `style.css` 的 `--stage-h`（手机默认 `36svh`；最后一页铺满整屏） |
| 翻页速度 | `style.css` 的 `--flip` 与 `app.js` 的 `FLIP`（两处保持一致） |
| 换姑娘 / 彩虹的照片 | 直接覆盖根目录的 `pic1.png` / `pic2.jpg`（文件名不变即可，页面按名字引用；换完记得硬刷新） |
| 照片浮现的时机 | `app.js` 里 `sceneGirl()` 的 1700ms、`sceneRainbow()` 的 `PHOTO_AT = 3400` |
| 爱心烟花的位置/数量 | `sceneRainbow()` 里的 `hp` 数组（三发爆点）与 `side * (.018 + .003 * fired)`（大小） |
| 翻页手势灵敏度 | `app.js` 的 `bindGestures()`：28px 位移阈值、0.55 速度阈值 |
| 某段动画 | `assets/app.js` 里对应的 `sceneXxx()`，每个场景都是独立函数，画完即返回 |
| 分享卡片 | `assets/og.png`（1200×630，替换同尺寸图片即可） |

想加一个新场景：写一个 `sceneXxx(w, h)`（返回 `{draw(t, dt)}`），注册到 `SCENES` 里，
然后在 HTML 里新增一页写 `data-scene="xxx"` 就行。

## 兼容性与实测

用 Playwright 在真实浏览器里跑过：

| 项目 | 结果 |
|---|---|
| 视口 `360×640 / 390×844 / 430×932 / 740×360 / 1280×800` | 无横向溢出、无纵向滚动 |
| 13 页逐页文案比对 | 与原文逐字一致 |
| 翻页方式：上滑 / 下滑 / 点击 / 滚轮 / 方向键 / Home | 全部通过 |
| 最后一页画布铺满 | 652 / 664 px |
| 画布左上角序号与标题 | 已移除 |
| 控制台报错 | 无 |
| 帧率（蝴蝶场景，无 GPU 的 headless 环境） | 60fps |
| 真机触摸事件（CDP 派发）上滑 / 下滑翻页 | 通过，`pointercancel = 0`；对照实验用 `manipulation` 会复现 `pointercancel = 1` 且翻页失败 |
| pic1 / pic2 是否真的画上画布 | 中心像素取样确认（纸面 ≈ (240,238,231)，照片明显偏离） |
| 减弱动态效果 / 无 JS / 打印 | 均有兜底 |

浏览器要求：支持 Canvas 2D 与 Pointer Events 的现代浏览器（iOS Safari 13+、Chrome 80+ 均可）。
`ctx.filter`（模糊）与 `svh` 不支持时会自动降级，不影响使用。
